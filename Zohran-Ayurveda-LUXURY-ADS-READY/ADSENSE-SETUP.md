# Zohran Ayurveda — AdSense setup

This build includes the Google AdSense site code for publisher `ca-pub-1045049664709570` and `public/ads.txt`.

## Recommended AdSense settings

Keep the premium storefront ad-free and monetize the Journal. In AdSense, use **Page exclusions** for:
- `/`
- `/products/*`
- `/checkout`
- `/cart`
- `/account`
- `/login`
- `/track-order`

Allow Auto ads on `/blog` and `/blog/*`.

After deploying to Vercel, return to the AdSense site page, tick **I've placed the code**, click **Verify**, then **Request review** when enabled.

Do not put private API keys or passwords in this file.
